
## Project goals:
This project will develop a “diagnostic assessment copilot” that supports instructors in rapidly creating high-quality assessment tasks aligned to course learning goals.

- **Item Generation Module/Agent**
It can automatically generate multiple choice (MC) items with diagnostically rich distractors so that each MC item is capable of measuring a defined combination of goal facet(s) and coherently related misconceptions as informed by the facet map.

- **Item Facet Mapping Module/Agent**
LLM will be used as a judge to evaluate how well those auto-generated items assess the intended construct, thereby providing feedback to the item generation module.
