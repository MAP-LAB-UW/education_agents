## Facets

Facets represent the learning dimensions for a particular topic, which could include major conceptual dimensaions that students should understand as well as a list of misconceptions that students often fall into. We will start by focusing on the statistics course, and specifically focus on the confidence intervals topic.

We will be working with the following facets:

|             |                                                                                                                                                                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Facet       | Text                                                                                                                                                                                                                                  |
| Goal        |                                                                                                                                                                                                                                       |
| A1          | Students understand that as sample size increases, standard errors of sampling distribution become smaller, sampling distribution will become tighter                                                                                 |
| A2          | Students understand that as sample size increases, sampling distribution will be closer to normal distribution (it does not mirror population distribution) with mean equals population mean                                          |
| A3          | Students can correctly interpret the confidence level as the percentage of times (i.e., understand the implications of replications)                                                                                                  |
| A4          | Students understand CI is used to capture true population parameter, not sample statistics                                                                                                                                            |
| A5          | Students understand that critical value depends on confidence level, and CI width increases when confidence level increases                                                                                                           |
| A6          | Students understand that when sample sizes increase, CI width shortens. \[this may include A1]                                                                                                                                        |
|             |                                                                                                                                                                                                                                       |
| Problematic |                                                                                                                                                                                                                                       |
| B1          | Sampling distribution is derived from a single dataset or is the same as sample distribution. \[Confusion about sampling distribution vs. sample distribution]                                                                        |
| B2          | Sampling distribution mirrors population distribution. \[Hence the standard deviation of the sampling distribution **stays the same** regardless of sample size] \[Confusion about sampling distribution vs. population distribution] |
| B3          | As sample size increases, sampling distribution will be more spread out\[Misunderstand how sample sizes impact standard error]                                                                                                        |
| B4          | As sample size increases, sampling distribution will be closer to population distribution \[not the same as B2]                                                                                                                       |
| B5          | As sample size increases, sampling distribution will be more concentrated                                                                                                                                                             |
| B6          | The mean of the sampling distribution depends on sample size                                                                                                                                                                          |
| B7          | CI is interpreted as probabilities of including true population means                                                                                                                                                                 |
| B8          | CI is interpreted as probabilities of including sample means                                                                                                                                                                          |
| B9          | CI estimates sample statistics (e.g., mean) instead of population parameters                                                                                                                                                          |
| B10         | CI estimates true scores instead of population parameters                                                                                                                                                                             |
| B11         | Higher confidence leads to more precise estimate, and hence shorter interval                                                                                                                                                          |


### Examples with Facet Mapping

#### Example 1
Suppose you constructed a particular confidence interval. What does this confidence interval mean? 

Which of the following is true about the meaning of 95% confidence?

1. 95% of the infinite intervals you could construct would contain the sample’s scores.

2. 95% of the infinite intervals you could construct would contain the sample’s mean.

3. 95% of the infinite intervals you could construct would contain the true scores.

4. 95% of the infinite intervals you could construct would contain the true mean.

**Facet mapping:**

1: B9

2: B9

3: B9

4: A4

#### Example 2

A 95% confidence interval for the mean number of televisions per American household is (1.15, 4.20). For each of the following statements about the above confidence interval, choose true or false.

1. The probability that μ is between 1.15 and 4.20 is .95.

2. We are 95% confident that the true mean number of televisions per American household is between 1.15 and 4.20.

3. 95% of all samples should have x-bars between 1.15 and 4.20.

4. 95% of all American households have between 1.15 and 4.20 televisions.

5. Of 100 intervals calculated the same way (95%), we expect 95 of them to capture the population mean.

6. Of 100 intervals calculated the same way (95%), we expect 100 of them to capture the sample mean.

**Facet mapping:**

1: a4, b7

2: a3, a4

3: a3, b9

4: b9, b1

5: a3, a4

6: a3, b9
